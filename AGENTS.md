# AGENTES — Porta communis collaboratorum

Hoc fasciculum brevem intentionally servamus. Fons veritatis non hic duplicandus est.

Omnis agens qui in hoc repositorio operatur ante mutationem:

1. `ARCHITECTURA.md` legat — **lex** operis;
2. `CONSILIUM.md` legat — **via** operis;
3. `CONTRIBUTING.md` legat — disciplina contributionis;
4. statum recentem Git inspiciat — **historia et res praesens**.

Noli opus `ACTIVUM` aut `RESERVATUM` ab alio agente duplicare sine inspectione. Si usor nullum novum mandatum expresse dat, sequere primum opus maximae prioritatis in `CONSILIUM.md` quod `PARATUM` est et non impeditur.

Si Git et `CONSILIUM.md` dissentiunt, Git praevalet et tabula corrigenda est. Si `CONSILIUM.md` et `ARCHITECTURA.md` dissentiunt, `ARCHITECTURA.md` praevalet.

**ARCHITECTURA est lex. CONSILIUM est via. Git historia est.**
