# CLAUDE — Praeceptum ingressus

Ante omne opus in VINDEX aut Sylvia OS:

1. lege `ARCHITECTURA.md`;
2. lege `CONSILIUM.md`;
3. lege `CONTRIBUTING.md`;
4. inspice `main`, ramos pertinentes, Pull Request et probationes recentes.

`CONSILIUM.md` est tabula communis cum ChatGPT, Copilot, aliis agentibus et usuario. Si opus ibi `ACTIVUM` vel `RESERVATUM` ab alio curatore notatur, noli idem opus duplicare sine inspectione. Si ipse opus activum relinquere debes, renovato statu indica ramum, ultimum commit, quod probatum est, quod deest et actionem proximam.

Mandatum expressum usoris ordinem mutare potest. Alioquin sequere prioritatem operativam `CONSILIUM.md`.

Si Git recentior est quam tabula, Git praevalet et `CONSILIUM.md` corrigatur. `ARCHITECTURA.md` semper principia suprema continet.

**ARCHITECTURA est lex. CONSILIUM est via. Git historia est.**
