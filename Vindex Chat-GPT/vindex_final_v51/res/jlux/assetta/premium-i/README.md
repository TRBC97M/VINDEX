# Asseta Premium I

Fontes PNG huius directorii sunt ars canonica P16-XI-A. Derivata `.simg` non duplicantur in Git: `instrumenta/genera_asseta_premium_i.py` ea deterministice ad build/test creat, deinde SIMG II et Graphica IX eadem octeta runtime consumunt.

Scalae: `@1x` = 48 px / 1000, `@1_5x` = 72 px / 1500, `@2x` = 96 px / 2000.
