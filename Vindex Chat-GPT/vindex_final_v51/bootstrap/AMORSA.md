# Amorsa fiduciae

Directorium `bootstrap/python/` minimum compilatorem Python continet. E fonte
VINDEX compilatorem nativum restituit et sic fiduciam in binario tradito
minuit.

```bash
./bootstrap/reconstruit.sh
```

Catena:

1. `bootstrap/python/compilateur.py` fontem compilatoris VINDEX compilat;
2. compilator amorsae eundem fontem in generationem nativam primam convertit;
3. generatio prima secundam producit;
4. duae generationes byte pro byte comparantur;
5. punctum fixum cum `compilator_vindex` distributo comparatur.

Exitus ad viam electam scribi potest:

```bash
./bootstrap/reconstruit.sh ./compilator_reconstructus
```

Instrumenta Python ad amorsam pertinent; lingua et compilator cotidiani sine
Python operari possunt. Verificator provectus et Officina tamen Python 3
requirunt.
