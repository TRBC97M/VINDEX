# Exempla VINDEX

Hoc directorium programmata maiora continet: lectores archivi, discretorem
verborum, arborem syntacticam atque terminale minimum.

Ex radice, exempli gratia:

```bash
./vindexc examples/terminal.vindex -o /tmp/terminale-vindex
/tmp/terminale-vindex
```

Exempla quae semet ipsa legunt e directorio `examples/` exsequenda sunt, quia
viae archivorum relativae sunt.
